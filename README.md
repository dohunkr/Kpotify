# Kpotify

Windows용 Spotify 데스크탑 앱(`%APPDATA%\Spotify`)의 가사를 실시간으로 한국어로 자동 번역해 주는 확장 프로그램입니다.

## 주요 기능
- **원클릭 설치 / 제거**: `install.bat` 더블 클릭 한 번으로 `xpui.spa`에 확장 스크립트를 자동 적용하고 Spotify를 재실행합니다. (Spicetify 불필요, SpotX 등 기존 패치와 호환)
- **실시간 가사 자동 번역**: 일반 가사 화면, 전체화면 가사, 우측 재생 중 사이드바 가사 등 모든 가사 뷰를 자동 감지해 한국어로 번역합니다.
- **한국어 가사 자동 건너뛰기**: 이미 한국어인 가사는 번역하지 않고 원문을 유지합니다.
- **배치 번역 & 로컬 캐시**: 가사 줄을 묶어서 번역하고 `localStorage`에 캐시하여 재생/스크롤 시 즉시 표시됩니다.
- **표시 모드 전환**: 가사 화면 우측 하단의 **`가사 번역`** 버튼으로 모드를 변경할 수 있습니다.
  - `원문 + 번역` (기본값)
  - `번역만 보기`
  - `번역 끄기`
  - `번역 캐시 비우기`

## 설치 방법
1. `install.bat` 파일을 더블 클릭합니다.
2. 실행 중인 Spotify가 자동으로 종료된 뒤 패치가 적용되고 다시 실행됩니다.

> **참고**: Spotify가 자동 업데이트되면 `xpui.spa`가 덮어씌워질 수 있습니다. 업데이트 후 가사 번역이 안 보이면 `install.bat`을 다시 한 번 실행해주세요.

## 제거 방법
- `uninstall.bat` 파일을 더블 클릭하면 Kpotify 스크립트만 깔끔하게 제거됩니다. (원본 백업은 `Apps\xpui.spa.kpotify.bak`에 보관됩니다.)
